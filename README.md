Google Apps Script I've created or generated to complete my work.

1. File Tree Pathing -- Generated with Google Gemini. Given a root folder ID, systematically generates the full file tree structure.
2. Generate Registration GForm -- Generated with Claude by supplying a list of form labels + options. Claude could not outright create the form for me, so the workaround is an Apps Script execution.
3. WLP Audit Script v2 -- Vibe coded with Claude. Systematically iterate through files and subfolders, given a root folder ID, to extract Weekly Lesson Plan data (expected format: xlsx or Google Sheets), and output as .json files for further processing.
4. File status check -- Manually coded. Paths through subfolders given a root folder ID, and reports back which subfolders are empty. Used to check existence of academic documents in designated subfolders.
